# 答辩演示脚本

## 90秒主线

“现在模拟一笔境外咨询服务费到达工行。系统先读取原始 `pacs.008.001.08` 汇入报文，再自动创建唯一Case，并同步给企业一个待办。”

企业端确认 `USD 80,000` 属于本企业，选择服务贸易。动态材料规则要求年度服务合同与本次Invoice；企业上传Invoice，合同保留为历史证据引用。

点击提交银行审核。强调四层链路：原始XML是事实源；金额、币种、收款主体、合同有效期和材料完整性由确定性规则检查；主体名称只做标准化与相似度提示；风险结论由银行风险系统返回，AI不判断“无风险”。

切换“系统运行”，展示21个节点、风险系统CLEAR、可信决策门和人工接管点，再切换银行经办端。展示原始报文、结构化字段、证据侧栏和主体人工确认。依次完成经办、复核、演示入账。

回到企业端，展示到账结果和到账后资金服务选择。选择“即期结汇”时说明报价是演示汇率，只记录企业意向，不执行真实交易。

## 备用Case

- `TT-IN-20260910-002`：USD 30,000，展示 `FAST_REVIEW`，说明低金额且证据完整时仍保留人工动作。
- `TT-IN-20260910-003`：USD 120,000，但Invoice只有USD 102,000，展示 `SUPPLEMENT_REQUIRED`，说明冲突证据不能被AI包装成“快速处理”。
